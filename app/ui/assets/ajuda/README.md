# Assets do Centro de Ajuda

`guias.json` é o catálogo versionado dos guias distribuídos com a aplicação.
Cada passo referencia uma ilustração em `slides/` e contém as falas dos dois
narradores.

O leitor mostra sempre a transcrição e sintetiza as falas localmente através da
voz do Windows. Quando houver duas vozes compatíveis, usa-as; caso contrário,
altera o tom e ritmo para distinguir Marta de João. Não são necessários
ficheiros de áudio, internet ou credenciais.
