# Scripts

Operational and developer scripts will be added here when needed.

## Subpastas

- [`imos_ferragens/`](imos_ferragens/README.md) — pôr uma ferragem nova na biblioteca do
  iMos a partir do STEP do fabricante: DWG 3D para `I:\Library\ConnDWG` e imagem 256×256
  para `I:\Library\Info\BITMAPS` (usa o kernel do iX CAD, sem abrir o programa).
